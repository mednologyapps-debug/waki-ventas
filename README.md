# WAKI Ventas - Bloque 1

Incluye login Supabase, validación con get_my_sales_access(), home mobile-first, selector de distrito, cantidad de hoteles y modo vehículo/caminando.

## Ejecutar
1. Copia `.env.example` como `.env`.
2. Agrega `VITE_SUPABASE_PUBLISHABLE_KEY`.
3. Ejecuta `npm install` y luego `npm run dev`.

La cuenta debe existir en `public.sales_staff` con `is_active = true`.
